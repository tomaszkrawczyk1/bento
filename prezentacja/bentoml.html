Czym jest BentoML

Framework do budowania i wdrażania usług AI/ML

Service
Klasa Pythona opisująca logikę i konfigurację usługi
API
Metoda dostępna przez HTTP, z typami wejścia i wyjścia
Runtime
Procesy serwera, obsługa żądań i ustawienia ruchu
Bento
Wersjonowany pakiet kodu, zależności i konfiguracji

    def run(self, request: dict) -> dict:
        with LOCK:
            return process(request)

Dane z Kaggle zostają na serwerze

Agent przekazuje link,
serwer pobiera plik.

  • Kaggle, upload, URL lub SQL
  • Cache pliku przypisany do wersji i zespołu
  • Schemat i ID zamiast rekordów Kaggle w kontekście
  • Token Kaggle montowany tylko w bramce
dataset_from_kaggle(
  reference="uciml/iris",
  file="Iris.csv",
  version=2
)

# Odpowiedź:
# dataset_id, rows, columns
# version, cache_hit
# preview: []

Bez limitu rozmiaru pliku w aplikacji. Bez limitu liczby wierszy i kolumn w aplikacji. Wykonalność zależy od pamięci modelu.

Demo: Kaggle i domyślny TabICLv2

„Pobierz zbiór uciml/breast-cancer-wisconsin-data i oceń przewidywanie kolumny diagnosis. Wyklucz id i pustą kolumnę. Użyj domyślnego modelu.”

Odtworzenie zapisanego przebiegu, bez połączenia z API
  1. 1. Lista plików i przypięcie wersji 2
  2. 2. Import data.csv: 569 wierszy, pusty podgląd źródła
  3. 3. evaluate: TabICLv2, 30 cech, podział 80/20, seed 42
  4. 4. Wynik testu: accuracy 99,12%, ROC AUC 0,9974

Wariant na żywo: ten sam prompt w kliencie MCP. Bez wpisywania tokenu Kaggle i przenoszenia CSV do czatu.
